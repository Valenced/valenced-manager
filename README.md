# 💊 Valenced Manager

![GitHub Workflow Status (with event)](https://img.shields.io/github/actions/workflow/status/Valenced/valenced-manager/release.yml)
![Open Software License 3](https://img.shields.io/badge/License-OSL%20v3-yellow.svg)

Application to use Valenced on Android.

## ❓ About

Valenced Manager is an application that installs and updates [Valenced](https://github.com/Valenced/valenced),
a modification for Discord.

## 💪 Features

Some of the features Valenced Manager provides are:

- 📲 **Install**: Download Discord and install Valenced on it
- 🔁 **Update**: Update Valenced to the latest version
- 🔔 **Notifications**: Be notified when a new version of Valenced is available
- 📃 **Changelog**: See the changelog of Valenced

## 🔽 Download
