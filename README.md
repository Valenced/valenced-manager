## 🔽 Download

Download the latest version of Valenced Manager from [here](https://github.com/Valenced/valenced-manager/releases/latest).

## ✨ Features

Some of the features Valenced Manager provides are:

- 📲 **Install**: Download Discord and install Valenced on it
- 🔁 **Update**: Update Valenced to the latest version
- 🔔 **Notifications**: Be notified when a new version of Valenced is available
- 📃 **Changelog**: See the changelog of Valenced
